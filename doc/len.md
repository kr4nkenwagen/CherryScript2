# LEN
## Overview
Returns the length of a variable as a number.

| type | Description |
| [`string`](string.md) | Returns the number of characters in the `string`. |
| [`number`](number.md) | Returns the number of characters in the `number`. |
| [`array`](array.md) | Returns the number of items in the `array`. |
| [`file`](file.md) | Returns the number of lines in the `file`. |


## Example
```
var length = len("Hello World")
```
