# VARIABLES
## Overview
Variables can be initialized using [`var`](var.md) or [`const`](const.md). Variables are untyped but will exist in the following types

| Type | Description |
|------|-------------|
| [`number`](number.md) | Numeric values that can be used to for arithmitics. |
| [`string`](string.md) | Strings of character.
| [`boolean`](boolean.md) | Binary value. |
| [`file`](file.md) | File handler. |
| [`json`](json.md) | json object. |
| [`vector`](file.md) | Vector containing `.x`, `.y`. `.z.` |
| [`array`](array.md) | Contains multiple variables that can be accessed by `identifier[index]`. |
| [`null`](null.md) | Empty variable. |


## Examples
### Number
```
var num = 123
```

```
var num = 1.23
```

```
var numb = .123
```

### String
```
var str = "string"
```

```
var str = 'string'
```

### Boolean
```
var bool = false
```

```
var bool = true
```

### File
```
var file = @"file/location"
```
